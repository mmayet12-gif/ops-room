The method in five lines

  1. Fetch each match once from ESPN's free feed, cache it, load it into a database, and reconcile it to the final score.
  2. Write the dossier before kick-off: patterns with fixed tests, committed to git so the time is on record.
  3. After full time, a script marks each pattern Held, Did not hold or No basis, by rules fixed in advance.
  4. Every number comes from a script with a sample size; one-match charts say "descriptive, not a trend".
  5. A separate reviewer checks the page before it goes live. What the feed cannot show is listed, not estimated.
