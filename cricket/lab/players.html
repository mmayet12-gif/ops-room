Tool 2 · Players

Runs, wickets and wins above average

Every ball is compared with what an average player does from the same game state and conditions. Positive is better than average, for batters and bowlers alike.

Player table

What the columns mean
RAA
Runs above average: runs minus the expected runs for the same balls left, wickets down, par/target and innings. Bowlers: expected runs conceded minus actual.
WAA
Wickets above average. Batters: expected dismissals minus actual (positive = got out less). Bowlers: wickets minus expected.
/100
Per 100 balls faced or bowled.
Impact, IR
Runs added using the resource curve, so a wicket costs runs; IR is Impact per 100 balls.
WPA
Win probability added, summed over the player's balls; roughly "matches won".
pLI
Average leverage of the player's balls (1 = an average ball of that innings).
Clutch
T20 Lab definition (the primer has none yet): WPA / pLI minus context-neutral WPA. Shown only with 300+ balls and 50+ high-leverage balls.
Hi−Lo
Impact per 100 balls when leverage > 1.5 minus when leverage < 1 (50+ balls of each).
